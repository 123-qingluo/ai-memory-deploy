## 每轮 reminder 的三块内容

按顺序拼进 prompt，越靠后离用户消息越近：

### ① 命令手册（静态）

把 `templates/command_manual.md` 原文常驻 system prompt，不要每轮重复生成。

### ② 最新 10 条活跃记忆标题（动态）

```
[活跃记忆标题] 最近更新的 10 条（这不是全部记忆，不要把这个列表当作全集）：
- {title}
- {title}
```

**必须带那句附注**。没有它，模型会把"列表里没有"当成"从未发生"。

### ③ 临时便签（动态，ONCE 消费）

```
[临时便签]（已消费，不进长期检索）：
- {content}
```

## 自动预取块（每轮，独立于 reminder）

```
[记忆预取] 以下可能是相关记忆（不是全部；未列出不代表没有）：
- (事实/偏好) {title}：{summary}
- (事件) {title}：{summary}
需要确认时先检索；没有记录就说不记得，不要编造。
```

## 注入顺序

人设/技能路由 → 文档 → 关系判定 → 输出长度 → 审批 → 自述台账（v1 未实现） → 工具告警 → 自动预取 → 闪回（v1 未实现）。
数值越大越先执行；**记忆块放在靠后位置**，让它像"刚想起来"，而不是开场白。
